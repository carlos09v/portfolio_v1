## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/carlos09v/portfolio_v1.git

# Acesse o diretório
cd portfolio_v1

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
